# while-loop-swift
Swift while loop demonstrations with various patterns and use cases

This repository provides comprehensive examples of the `while` loop implemented across several popular programming languages. The `while` loop is a fundamental control structure used to execute a block of code repeatedly as long as a specific condition remains true.

## 📚 Language Implementations

Explore the detailed, commented code examples and conceptual explanations for the `while` loop in the following languages:

*   [Java](examples/java_while_loop.md)
*   [PHP](examples/php_while_loop.md)
*   [Swift](examples/swift_while_loop.md)
*   [C++](examples/cpp_while_loop.md)

Each file contains a descriptive explanation of the `while` loop concept and a complete, runnable code block demonstrating its usage.
