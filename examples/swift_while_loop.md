# Swift While Loop
## Overview
In Swift, the while loop is a fundamental control structure used for repeating a block of code while a certain condition is met. It's particularly useful when the number of iterations is unknown beforehand.
## Example
```swift
var i = 0
while i < 10 {
    print(i)
    i += 1
}
```
This Swift example illustrates the use of a while loop to print numbers from 0 to 9.
