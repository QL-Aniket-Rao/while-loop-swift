# PHP While Loop
## Overview
The while loop in PHP is used to execute a block of code repeatedly as long as a certain condition is true. It is useful for scenarios where the number of iterations is not fixed.
## Example
```php
$i = 0;
while ($i < 10) {
    echo $i . "\n";
    $i++;
}
```
This PHP example shows how to use a while loop to print numbers from 0 to 9.
