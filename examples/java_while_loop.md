# Java While Loop
## Overview
The while loop in Java is a control flow statement that allows code to be executed repeatedly based on a given boolean condition. It continues to execute the block of code within the loop as long as the condition is true.
## Example
```java
public class WhileLoopExample {
    public static void main(String[] args) {
        int i = 0;
        while (i < 10) {
            System.out.println(i);
            i++;
        }
    }
}
```
This example demonstrates a basic while loop in Java, printing numbers from 0 to 9.
