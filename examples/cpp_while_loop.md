# C++ While Loop
## Overview
The while loop in C++ is a control structure that allows for the execution of a block of code as long as a specified condition is true. It's versatile and commonly used for various iterative tasks.
## Example
```cpp
#include <iostream>
int main() {
    int i = 0;
    while (i < 10) {
        std::cout << i << std::endl;
        i++;
    }
    return 0;
}
```
This C++ example demonstrates how to use a while loop to print numbers from 0 to 9.
